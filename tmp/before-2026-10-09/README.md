# راهین | RAHIN

وب‌سایت دوزبانه‌ی تیم شش‌نفره‌ی راهین. HTML، CSS و JavaScript ساده، بدون فریم‌ورک، نصب یا وابستگی آنلاین. فونت وزیرمتن، فونت‌های لاتین و همه‌ی تصاویر محلی‌اند.

**راه را پیدا می‌کنیم. با هم می‌سازیم.**

## اجرا و تحویل

`index.html` را در مرورگر باز کنید. اگر نسخه‌ی قبلی باز است، صفحه را تازه‌سازی کنید. برای انتقال پروژه، کل پوشه را کپی کنید یا بسته‌ی `output/RAHIN-portfolio.zip` را از حالت فشرده خارج کنید. اجرای HTML به تنهایی بدون پوشه‌ی assets و فایل‌های JS/CSS کافی نیست.

راه اختیاری پیش‌نمایش HTTP:

```bash
python3 -m http.server 4173
```

سپس `http://localhost:4173` را باز کنید. انتشار عمومی انجام نشده است.

## ساختار

- `index.html`: ساختار معنایی صفحه و متن اولیه‌ی انگلیسی
- `content.js`: متن‌های فارسی و انگلیسی، اعضا، حوزه‌های همکاری، مراحل و نمونه‌ها
- `script.js`: زبان، منو، نمودار، فرم، پنجره‌ی نمونه‌ها و انیمیشن‌ها
- `style.css`: رنگ‌ها، فونت، RTL، واکنش‌گرایی و حرکت
- `assets/logo/rahin-logo.svg`: لوگوتایپ و نماد وکتور، مستقل از فونت
- `assets/logo/rahin-mark.svg`: نماد مسیر/R؛ نسخه‌های `-light` برای زمینه‌ی روشن و `-mono` تک‌رنگ‌اند
- `assets/logo/favicon.svg`: آیکون مرورگر
- `assets/avatars/`: شش آواتار انتزاعی و نسخه‌های روشن
- `assets/fonts/`: فونت‌های محلی و مجوزها
- `portfolio.html`: منبع چاپی PDF فارسی
- `output/pdf/RAHIN-Team-Portfolio-FA.pdf`: معرفی فارسی دوصفحه‌ای A4
- `docs/design-notes.md`: منابع بررسی‌شده و تصمیم‌های متن، هویت و تجربه
- `tools/`: ابزارهای اختیاری توسعه و آزمون
- `qa/verification.json`: گزارش جاری آزمون‌ها
- `qa/rahin-lighthouse.json`: گزارش جاری Lighthouse
- `qa/rahin-*.png`: تصاویر بررسی نسخه‌ی راهین

## ویرایش محتوا

1. متن‌های اصلی در `translations.en` و `translations.fa` از `content.js` قرار دارند. کلیدهای هر دو زبان یکسان‌اند. متن اولیه‌ی HTML نیز هنگام تغییر متن‌های اصلی به‌روز شود.
2. آرایه‌ی `members` شامل پوریا، تیام، امیرمحمد، ساینا، حسام و زهرا است. `bio/faBio` معرفی، `line/faLine` جمله‌ی اختصاصی، `tone` رنگ و `avatar` تصویر را کنترل می‌کنند. فقط نام کوچک در سایت آمده؛ عنوان نقش‌ها و دکمه‌ی معرفی بیشتر وجود ندارند. عدد اعضا از طول آرایه محاسبه می‌شود.
3. آرایه‌ی `roles` حوزه‌های همکاری را تعریف می‌کند. پنج بخش خدمات مستقل از تعداد شش عضو هستند؛ این آرایه به معنای پنج عضو یا نقش رسمی آن‌ها نیست.
4. `cases` کارت‌ها و `caseDetails` متن پنجره‌ی هر نمونه را تعریف می‌کنند. برای افزودن نمونه، یک ورودی متناظر به هر دو اضافه کنید. برای پروژه‌ی واقعی، برچسب وضعیت را نیز در `renderCases` به‌روز کنید.
5. `methods` مراحل و `journey` موارد توافق پیش از شروع را تعریف می‌کنند. توضیحات جزئی مراحل در `script.js` کنار توابع مربوطه‌اند.
6. رنگ‌ها در `:root` فایل CSS هستند. لوگو، فاوآیکون، هدر، فوتر و تصویر سه‌بعدی همگی از همان نماد راهین استفاده می‌کنند.
7. برای عکس واقعی، `avatar` را تغییر دهید؛ اندازه‌ی تصویر را ثابت نگه دارید. آواتار تزئینی فعلی alt خالی دارد چون نام کنار تصویر دیده و خوانده می‌شود.

## واقعیت محتوا و تماس

معرفی‌ها از اطلاعات ارائه‌شده‌ی اعضا نوشته شده‌اند و بر شیوه‌ی فکر کردن، مسئولیت‌پذیری و سهم هر نفر در همکاری تمرکز دارند. نام ابزارها، فناوری‌ها و عنوان‌های تخصصی از معرفی اعضا حذف شده است. لحن کلی‌تر، سابقه یا توانایی تازه‌ای به کسی نسبت نمی‌دهد.

نمونه‌ها به‌وضوح «مفهومی» هستند؛ مشتری، رضایت‌نامه، نتیجه‌ی تجاری یا سابقه‌ی ساختگی اضافه نشده است. نشانی تماس و حساب اجتماعی جعلی در سایت وجود ندارد.

فرم «شرح پروژه» متن را در همان مرورگر به فایل UTF-8 تبدیل می‌کند. **این فرم هیچ پیامی ارسال نمی‌کند.** برای دریافت درخواست واقعی، `renderContact` را با ایمیل/لینک معتبر یا سرویس ارسال فرم تکمیل کنید. این محدودیت کنار فرم نیز مشخص است.

فقط انتخاب زبان در `localStorage` ذخیره می‌شود. ترجیح زبان نسخه‌ی قبلی به‌صورت سازگار خوانده می‌شود. مسدود بودن storage مانع اجرای سایت نیست.

## حرکت و دسترسی‌پذیری

- سه‌بعدی به‌طور پیش‌فرض فعال است و دکمه‌ی خاموش/روشن ندارد. ترجیح `prefers-reduced-motion` سیستم همچنان محترم است.
- شکل‌گیری لایه‌ها و ترسیم لوگو هنگام ورود محدود و یک‌باره است؛ انیمیشن پس‌زمینه‌ی دائمی اضافه نشده است.
- اشاره‌گر دقیق فقط هندسه‌ی تزئینی را حرکت می‌دهد. خروج اشاره‌گر، پنهان‌شدن تب، خروج صحنه از دید یا کاهش حرکت آن را متوقف می‌کند.
- ورود بخش‌ها از opacity/transform استفاده می‌کند. فاصله‌ی ورود هم‌زمان آیتم‌ها ۹۰ میلی‌ثانیه با سقف ۲۷۰ میلی‌ثانیه است. فوکوس کیبورد آیتم را فوراً آشکار می‌کند.
- اسکرول طبیعی مرورگر حفظ شده است. منوی بسته از مسیر Tab خارج می‌شود؛ پنجره‌ها Escape، کلیک بیرون، نگه‌داری و بازگرداندن فوکوس دارند.
- لوگوهای ثابت، متن‌ها، دکمه‌ها و نمایش اطلاعات به hover یا انیمیشن وابسته نیستند.

## آزمون‌های نسخه‌ی راهین

- اجرای مستقیم `file://`، آفلاین و فونت‌های محلی
- ۱۴ چیدمان: فارسی و انگلیسی در عرض‌های ۳۲۰، ۳۷۵، ۴۸۰، ۷۶۸، ۹۹۲، ۱۲۰۰ و ۱۴۴۰ پیکسل
- بدون اسکرول افقی یا هم‌پوشانی گره‌ها در این اندازه‌ها
- شش معرفی درون صفحه، نبود دکمه‌ی معرفی بیشتر و نبود کلید حرکت
- سه پنجره‌ی نمونه، بازگشت فوکوس، Tab، Shift+Tab، Escape و کلیک بیرون
- منوی موبایل، مراحل تعاملی، حفظ زبان، مسدود بودن storage و دانلود شرح پروژه
- حرکت سه‌بعدی پیش‌فرض و تغییر زنده‌ی reduced-motion
- بدون خطای JavaScript/console در مسیرهای آزموده‌شده
- axe-core در هر دو زبان: صفر نقض خودکار معیارهای بررسی‌شده
- Lighthouse موبایل محلی: Performance 100، Accessibility 100، Best Practices 100، SEO 100؛ LCP برابر 1.0s، CLS برابر 0.028 و TBT برابر 0ms

این امتیازها نتیجه‌ی اجرای آزمایشگاهی در Chrome هستند و تضمین عملکرد روی همه‌ی دستگاه‌ها نیستند. INP میدانی به داده‌ی بازدیدکننده نیاز دارد. بررسی خودکار جای ارزیابی انسانی کامل دسترسی‌پذیری را نمی‌گیرد.

## PDF و ابزارهای توسعه

PDF دو صفحه‌ی A4 با فونت‌های Embed شده است؛ هر دو صفحه به تصویر تبدیل و بازبینی شده‌اند. فایل چاپی جداگانه نگه‌داری می‌شود؛ تغییر محتوای سایت خودکار به PDF منتقل نمی‌شود.

برای خروجی دستی، `portfolio.html` را در Chrome باز کنید: A4، حاشیه صفر، Background graphics روشن و Headers/footers خاموش. برای خروجی تکرارپذیر:

```bash
node tools/export-pdf.cjs
```

ابزارهای اختیاری به Playwright/Chrome و برای آزمون دسترسی‌پذیری به axe-core نیاز دارند. مسیرها با `PLAYWRIGHT_PATH`، `CHROME_PATH` و `AXE_PATH` قابل تنظیم‌اند. آزمون axe به سرور محلی پورت 4173 نیاز دارد.

```bash
node --check content.js
node --check script.js
node tools/verify.cjs
```

خود سایت به Node یا این ابزارها وابسته نیست. نسخه‌های قبلی در `tmp/rahin-before` نگه داشته شده‌اند و در بسته‌ی قابل انتشار قرار نمی‌گیرند.
